More About Strings

You've used strings since your very first program, but they have far more to offer than just holding text. Because a string is a sequence of characters, the indexing and slicing you learned for lists work here too — and on top of that, strings carry a deep toolbox of methods for testing, searching, cleaning, and transforming text.

Foundation

Strings are sequences

A huge share of real programs spend their time examining and reshaping text — names, codes, messages, user input. Python gives strings a rich set of tools for exactly that. The key insight that unlocks most of them: a string is a sequence of characters, so the same indexing, slicing, in testing, and len you used with lists all work on strings too.

One big difference

Lists are mutable; strings are not. Everything that looks like "changing" a string actually builds a brand-new string. Keep that in mind — it explains a lot of how the string methods behave.

Basic operations

Accessing the individual characters

There are two everyday ways to reach the characters of a string: walk through them with a for loop, or jump straight to one by its index.

Iterating with a for loop

A for loop over a string hands you one character per pass — perfect when you need to look at every character, such as counting how many times a letter appears.

iterate.py
word = "Falcon"
for ch in word:
    print(ch)        # F, then a, l, c, o, n on its own line

Indexing

Every character has an index giving its position, starting at 0. Read one with word[i], which hands back a one-character string. Negative indexes count from the end, exactly as with lists.

indexing.py
motto = "Stay curious"
print(motto[0])      # S
print(motto[-1])     # s  (last character)
print(len(motto))    # 12
print(motto[12])     # IndexError: valid indexes are 0..11

Going past the end raises an IndexError. The len function returns the character count, so the last valid index is always len(string) - 1 — handy for keeping an index-based loop in bounds.

Basic operations

String concatenation

To concatenate is to append one string to the end of another. The + operator joins two strings into a new one, and += tacks a string onto the end of an existing variable.

concatenation.py
first = "Nova"
last  = "Vega"

full = first + " " + last
print(full)        # Nova Vega

greeting = "Hi"
greeting += " there"   # greeting is now "Hi there"
Watch the left side of +=

With +=, the variable on the left must already exist — otherwise Python raises a NameError. And + only joins string to string; "Age: " + 25 raises a TypeError. Convert the number first: "Age: " + str(25).

A defining property

Strings are immutable

Once a string is created, it cannot be changed. This surprises people, because concatenation looks like editing. What really happens is that Python builds a new string and points the variable at it — the original is left untouched.

immutable.py
tag = "hello"
tag[0] = "H"     # TypeError: strings can't be changed in place

Because of immutability, you can't assign to string[index]. To get a modified version, you build a new string — which is exactly what the string methods coming up do: they return a fresh copy and leave the original alone.

Substrings

String slicing

A slice is a span of characters taken from a string — a substring. The expression string[start:end] returns a new string with copies of the characters from start up to, but not including, end.

slicing.py
code = "ORD-48715"

print(code[0:3])   # ORD     start up to (not including) 3
print(code[4:])    # 48715   end defaults to len(code)
print(code[:3])    # ORD     start defaults to 0
print(code[-2:])   # 15      negative start
print(code[::2])   # OD475   step of 2

Omit start and Python uses 0; omit end and it uses len(string). A third value sets the step, and negative indexes work just as they do for single characters.

Testing & searching

Searching with the in operator

The in operator tells you whether one string appears inside another. The expression string1 in string2 is True when string1 is found somewhere in string2, and False otherwise. Its partner not in asks the opposite.

contains.py
sentence = "the quick brown fox"

if "quick" in sentence:
    print("found it")        # found it

print("slow" not in sentence)   # True
Testing & searching

String testing methods

A method is a function attached to an object; you call it as mystring.method(arguments). One family of string methods tests a string for some characteristic and returns a Boolean — True if the condition holds, False if not.

MethodReturns True when…
isalnum()the string is non-empty and every character is a letter or digit.
isalpha()the string is non-empty and every character is a letter.
isdigit()the string is non-empty and every character is a digit.
islower()every letter is lowercase (and there's at least one letter).
isupper()every letter is uppercase (and there's at least one letter).
isspace()the string is non-empty and every character is whitespace (space, \n, or \t).
testing.py
print("2026".isdigit())     # True
print("Falcon".isalpha())   # True
print("Bay12".isalnum())    # True
print("   ".isspace())      # True
print("Falcon".isupper())   # False
A common use

Testing methods make input validation tidy. Before converting typed text to a number, check user_text.isdigit() — if it's False, you can ask again instead of letting int() raise an exception.

Testing & searching

Modification methods

Another family returns a copy of the string with some change applied. Because strings are immutable, these never alter the original — they hand back a new string. That makes them feel like they "modify" a string while honoring immutability.

MethodReturns a copy with…
lower()every letter converted to lowercase.
upper()every letter converted to uppercase.
strip()leading and trailing whitespace removed.
lstrip()leading (left-side) whitespace removed.
rstrip()trailing (right-side) whitespace removed.
strip(char)the given character removed from both ends (also lstrip(char), rstrip(char)).
modifying.py
label = "   Falcon Ridge   "
print(label.strip())     # "Falcon Ridge"
print(label.upper())     # "   FALCON RIDGE   "
print(label)             # unchanged: "   Falcon Ridge   "

Case-insensitive comparison

String comparisons are case-sensitive: "Yes" and "yes" are not equal. To compare regardless of case, convert both sides with lower (or upper) first:

case_insensitive.py
answer = "YES"
if answer.lower() == "yes":
    print("confirmed")      # confirmed — matches "yes", "Yes", "YES", ...
Testing & searching

Searching and replacing

Programs constantly look for substrings and swap them out. Four methods cover most of that work.

MethodWhat it does
startswith(sub)returns True if the string begins with sub.
endswith(sub)returns True if the string ends with sub.
find(sub)returns the lowest index where sub appears, or -1 if it isn't found.
replace(old, new)returns a copy with every occurrence of old replaced by new.
search_replace.py
sku = "BOLT-22-MM"
print(sku.startswith("BOLT"))   # True
print(sku.endswith("MM"))       # True

sentence = "the quick brown fox"
print(sentence.find("brown"))   # 10  (index where it starts)
print(sentence.find("cat"))     # -1  (not found)
print(sentence.replace("fox", "cat"))
# the quick brown cat
find vs. in

Use in when you only need a yes/no answer about whether a substring is present. Use find when you also need to know where it is — remembering that a missing substring comes back as -1, not an exception.

Testing & searching

Repetition and splitting

The repetition operator

Applied to a string and an integer, * is a repetition operator: it makes that many copies of the string and joins them. The string is the left operand, the count the right (string * n).

repetition.py
divider = "=" * 20
print(divider)        # ====================
print("ab" * 3)        # ababab

Splitting a string

The split method breaks a string into a list of pieces. With no argument it splits on whitespace, giving you the words; pass a separator to split on something else, like a comma.

splitting.py
sentence = "the quick brown fox"
print(sentence.split())
# ['the', 'quick', 'brown', 'fox']

data = "red,green,blue"
print(data.split(","))
# ['red', 'green', 'blue']
A natural pairing

split is the bridge from text to data: take a line a person typed or a comma-separated record and turn it into a list you can loop over, index, and process with everything you learned about lists.

Review

Check yourself

Predict each answer, then open the card. Even better, try it in the console above.

Q1Given word = "Falcon", what are word[0] and word[-1]?▸

word[0] is "F" and word[-1] is "n". Indexing starts at 0, and negative indexes count back from the end.

Q2Why does greeting[0] = "H" raise an error?▸

Strings are immutable — you can't change a character in place. To get a changed version you must build a new string (for example with slicing and concatenation, or a method that returns a copy).

Q3What does concatenation really do to the original string, given strings are immutable?▸

Nothing — it leaves the original untouched. + and += build a brand-new string and rebind the variable to it; the old string is simply no longer referenced.

Q4What does "ORD-48715"[4:] return, and why?▸

"48715". With the end omitted, the slice runs from index 4 to the end of the string.

Q5How do you compare two strings without caring about case?▸

Convert both with the same method before comparing — e.g. answer.lower() == "yes". Comparisons are case-sensitive by default, so "YES" == "yes" is False.

Q6What's the difference between find and the in operator?▸

in gives a Boolean: is the substring present? find gives the index where it starts, or -1 if it isn't there. Use in for yes/no, find when you need the position.

Q7What does "red,green,blue".split(",") produce, and of what type?▸

A list: ['red', 'green', 'blue']. split returns a list of the pieces between the separator — with no argument it splits on whitespace instead.

Reference

Key terms

string
A sequence of characters.
character
A single element of a string.
index
A number giving a character's position; the first is 0.
negative index
An index counting from the end; -1 is the last character.
IndexError
Raised when a string index is out of range.
len function
Returns the number of characters in a string.
concatenation
Joining strings end to end with + or +=.
immutable
Describes an object that cannot be changed after creation.
rebinding
Pointing a variable at a new string rather than editing the old one.
slice
A span of characters copied with [start:end].
substring
A string that is part of a larger string; the result of a slice.
step
The optional stride in a slice, as in [::2].
in operator
Tests whether one string occurs within another.
not in operator
Tests whether one string is absent from another.
method
A function that belongs to an object, called with dot notation.
Boolean method
A method that returns True or False.
isalpha / isdigit / isalnum
Tests for all-letters, all-digits, or letters-and-digits.
isspace
Tests whether a string is all whitespace.
islower / isupper
Tests whether letters are all lower- or uppercase.
lower / upper
Return a copy converted to lower- or uppercase.
strip / lstrip / rstrip
Return a copy with whitespace (or a given character) removed.
case-sensitive
Treating upper- and lowercase letters as different.
startswith / endswith
Test whether a string begins or ends with a substring.
find
Returns the lowest index of a substring, or -1 if absent.
replace
Returns a copy with every occurrence of one substring swapped for another.
repetition operator
* applied to a string and an integer; copies and joins.
split
Returns a list of a string's pieces, divided on a separator.
separator
The character(s) split divides a string on.
whitespace
Spaces, tabs (\t), and newlines (\n).
