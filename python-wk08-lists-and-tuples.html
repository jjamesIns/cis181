Lists and Tuples

A single variable holds one value at a time. But programs constantly need to keep a whole batch of related values together — a week of temperatures, a roster of names, a grid of scores. Python's sequences do exactly that. This module is about the two you'll reach for most: the flexible, changeable list and its locked-down cousin, the tuple.

Foundation

Sequences

A sequence is an object that holds multiple items of data, stored one after another in a definite order. Because the order is fixed, every item has a position you can refer to. Python ships with several sequence types; the two you'll use constantly are the list and the tuple.

They behave almost identically — the headline difference is one word:

listMutable: it can change▸

A list's contents can be changed after it's created. You can replace an item, add new ones, remove some, or reorder the whole thing. Reach for a list whenever the collection needs to grow, shrink, or be edited as the program runs.

tupleImmutable: it cannot change▸

Once a tuple is created, its contents are locked. You can read from it all day, but you cannot add, remove, or replace items. Reach for a tuple when a group of values should stay fixed — and, as a bonus, Python can process it a little faster.

Almost everything in this module is shown with lists. Near the end, you'll see that tuples support the same reading operations — they simply forbid the ones that would change the contents.

The everyday sequence

Introduction to lists

A list is an object that contains multiple data items. Each item is called an element. You create a list by writing its elements inside square brackets, separated by commas.

make_lists.py
# A list of integers
elevations = [120, 340, 980, 1520, 1750]

# A list of strings
trails = ["Switchback", "Ridgeline", "Lakeshore", "Summit"]

# A list may even hold items of different types
marker = ["Switchback", 4, 2.6]

print(elevations)        # [120, 340, 980, 1520, 1750]
print(list("hike"))      # ['h', 'i', 'k', 'e']

The print function can display an entire list at once. The list() function converts certain objects — like a string or a range — into a list of their items.

The repetition operator and iterating

Applied to a sequence and an integer, the * symbol becomes a repetition operator: it makes that many copies of the list and joins them. The sequence goes on the left, the count on the right (list * n). It's a quick way to build a list of repeated values.

repeat_and_loop.py
scores = [0] * 5
print(scores)            # [0, 0, 0, 0, 0]

# Iterate over a list one element at a time
for trail in trails:
    print(trail)

Indexing

An index is a number that identifies an element's position. The first element's index is 0, the second is 1, and the last is len(list) - 1. Negative indexes count from the end: -1 is the last element, -2 the next-to-last, and so on.

Using an index that doesn't exist raises an IndexError exception. The len function returns how many elements a sequence holds, which lets you stay inside the valid range:

index_len.py
print(elevations[0])     # 120  (first)
print(elevations[-1])    # 1750 (last)

count = len(elevations)
print(count)             # 5
print(elevations[count])  # IndexError: valid indexes are 0..4

Lists are mutable

A mutable sequence is one whose items can be changed. Assigning to a valid index replaces that element in place:

mutate.py
trails[1] = "Gorge"
print(trails)
# ['Switchback', 'Gorge', 'Lakeshore', 'Summit']

Concatenating lists

To concatenate is to join two things together. The + operator joins two lists into a new one, and += appends one list onto the end of another. You can only concatenate a list with another list — not with a number or string.

concat.py
morning = ["Switchback", "Ridgeline"]
evening = ["Lakeshore", "Summit"]

day = morning + evening
print(day)
# ['Switchback', 'Ridgeline', 'Lakeshore', 'Summit']

morning += evening    # same effect, in place
Type mismatch

Writing day + 5 raises a TypeError. The + operator only concatenates a list with another list. To add a single value, wrap it first: day + [5].

Spans of a list

List slicing

A slice is a span of items taken from a sequence. The expression list[start:end] produces a new list containing copies of the elements from start up to — but not including — end.

slicing.py
data = [10, 20, 30, 40, 50, 60]

print(data[1:4])   # [20, 30, 40]
print(data[:3])    # [10, 20, 30]   start defaults to 0
print(data[3:])    # [40, 50, 60]   end defaults to len(data)
print(data[::2])   # [10, 30, 50]   step of 2
print(data[-2:])   # [50, 60]       negative start

Leave out start and Python uses 0; leave out end and it uses len(list). A third number, the step, controls the stride, and negative indexes work here just as they do for single elements.

Membership

Finding items with the in operator

The in operator tests whether an item appears in a list. The expression item in list evaluates to True if the item is present and False if it isn't. Its partner, not in, asks the opposite question.

membership.py
trails = ["Switchback", "Ridgeline", "Summit"]

if "Summit" in trails:
    print("That trail is on the map.")

if "Gorge" not in trails:
    print("No Gorge trail here.")
Why it's handy

Testing membership with in is far cleaner than writing a loop that compares every element by hand. Use it whenever you just need a yes-or-no answer about whether something is in the list.

The toolkit

List methods and useful built-in functions

A method is a function that belongs to an object and operates on it; you call it with dot notation, like items.append(x). Lists come with a rich set of methods for adding, finding, removing, and reordering elements.

MethodWhat it does
append(item)Adds item to the end of the list.
index(item)Returns the index of the first element equal to item. Raises ValueError if it isn't found.
insert(i, item)Inserts item at position i, shifting later elements toward the end.
sort()Rearranges the elements into ascending order, in place.
remove(item)Removes the first occurrence of item. Raises ValueError if it isn't found.
reverse()Reverses the order of the elements, in place.
list_methods.py
counts = [12, 5, 9, 5, 21]

counts.append(8)        # [12, 5, 9, 5, 21, 8]
print(counts.index(9))   # 2  (first position holding 9)
counts.insert(0, 30)    # 30 added at the front
counts.remove(5)        # only the FIRST 5 is removed
counts.sort()           # ascending order, in place
counts.reverse()        # flips the current order

The del statement and the min / max functions

The del statement removes the element at a specific index: del list[i]. The built-in min and max functions take a sequence as an argument and return its lowest or highest value.

del_min_max.py
readings = [58, 61, 47, 73, 66]

del readings[2]          # removes 47 -> [58, 61, 73, 66]
print(min(readings))    # 58
print(max(readings))    # 73
in place vs. returns a value

Notice that sort, reverse, append, and remove change the list in place and return None — so never write counts = counts.sort(). By contrast, index, min, and max hand back a value you can use or store.

A subtle trap

Copying lists

Assigning one list variable to another does not make a second list. Both names end up referencing the same list object, so a change made through one name is visible through the other.

To get a genuine, independent copy, you must copy the elements. Two classic approaches, plus two shorthands:

copying.py
original = [1, 2, 3, 4]

# Method 1: empty list + a loop that appends each element
copy1 = []
for item in original:
    copy1.append(item)

# Method 2: concatenate the old list onto an empty one
copy2 = [] + original

# Shorthands you'll see often
copy3 = original[:]      # a full slice
copy4 = list(original)   # the list() function
The test

With a true copy, changing copy1[0] leaves original untouched. With a mere alias, it wouldn't — because there was only ever one list.

Putting lists to work

Processing lists

List elements are ordinary values, so they can feed straight into calculations. Two of the most common tasks are totaling a list of numbers and averaging them.

To total a list, use a loop with an accumulator variable that starts at 0 and grows by each element. To average, divide that total by len(list).

total_average.py
donations = [25, 40, 10, 75, 50]

total = 0
for amount in donations:
    total += amount

average = total / len(donations)
print(total, average)   # 200 40.0

Passing and returning lists

A list can be passed to a function as an argument, and a function can return a list (really, a reference to one). This lets you package list-building logic neatly:

list_functions.py
def above(values, limit):
    keepers = []
    for v in values:
        if v > limit:
            keepers.append(v)
    return keepers          # hands back a new list

print(above([25, 40, 10, 75], 30))   # [40, 75]

Saving a list to a file

To write a list to a file, loop through it and write each element followed by '\n'. (The writelines method writes a list of strings but adds no newlines of its own.) To read the lines back, the file object's readlines method returns them as a list.

list_to_file.py
trails = ["Switchback", "Ridgeline", "Summit"]

outfile = open("trails.txt", "w")
for name in trails:
    outfile.write(name + "\n")
outfile.close()

infile = open("trails.txt", "r")
lines = infile.readlines()   # a list, with '\n' on each
infile.close()
A shorter way

List comprehensions

Building one list from another is such a common job that Python offers a compact expression for it. A list comprehension creates a new list by looping over an existing sequence — all in a single line, with the square brackets doing the work of the empty list and the append.

Look at the pattern you already wrote in the previous section, then the comprehension that replaces it:

the long way
elevations = [120, 340, 980, 1520, 1750]

feet = []                       # start empty
for m in elevations:            # walk the source list
    feet.append(round(m * 3.28))   # transform and collect

print(feet)   # [394, 1115, 3214, 4986, 5740]
the comprehension
feet = [round(m * 3.28) for m in elevations]

print(feet)   # [394, 1115, 3214, 4986, 5740]

Both produce exactly the same list. The comprehension simply states the intent — "the rounded conversion of every elevation" — instead of describing the machinery of building it.

The general form

Every list comprehension has three parts inside the brackets, and they always appear in this order:

general form
[expression for variable in iterable]
PartWhat it does
expressionWhat to put in the new list. Usually built from the variable — it may also be the variable alone.
variableThe target variable, receiving one item per pass, exactly as in a for loop.
iterableThe source being walked — a list, a tuple, a string, or a range.
Read it right to left

The for clause runs first, even though it is written second. Read [round(m * 3.28) for m in elevations] as: "for each m in elevations, put round(m * 3.28) in the new list." Reading it left to right is what makes comprehensions feel backwards at first.

more sources.py
trails = ["Switchback", "Ridgeline", "Lakeshore", "Summit"]

# from a list of strings
print([t.upper() for t in trails])
# ['SWITCHBACK', 'RIDGELINE', 'LAKESHORE', 'SUMMIT']

print([len(t) for t in trails])   # [10, 9, 9, 6]

# from a range
print([n * 3 for n in range(1, 6)])   # [3, 6, 9, 12, 15]

# from a string
print([c for c in "hike"])          # ['h', 'i', 'k', 'e']

Filtering with an if clause

Add an if at the end and the comprehension keeps only the items that satisfy the condition. Items that fail the test are simply not placed in the new list:

filtering.py
donations = [25, 40, 10, 75, 50]

large = [d for d in donations if d > 30]
print(large)    # [40, 75, 50]

short_names = [t for t in trails if len(t) < 10]
print(short_names)   # ['Ridgeline', 'Lakeshore', 'Summit']

Notice that the above function from the previous section — an empty list, a loop, an if, and an append — collapses to one line:

above_again.py
def above(values, limit):
    return [v for v in values if v > limit]

print(above([25, 40, 10, 75], 30))   # [40, 75]
Transform, filter, or both

The expression transforms; the if clause filters. Use either alone or both together. When the expression is just the variable — [d for d in donations if d > 30] — nothing is transformed and the comprehension is doing pure filtering.

When not to use one

A comprehension should make code easier to read, not harder. Reach for an ordinary loop when the body needs more than a single expression — several statements, a nested decision, or anything you'd want to comment line by line. If you cannot say the comprehension out loud in one breath, write the loop instead.

It always builds a new list

A comprehension never modifies the source. elevations is untouched by the examples above — the result is a separate list, which is why you must assign it to something. Writing the comprehension without storing it accomplishes nothing.

Lists of lists

Two-dimensional lists

A two-dimensional list — also called a nested list — is a list whose elements are themselves lists. It's natural to picture one as a table with rows and columns, which makes it perfect for multiple sets of related data.

To reach a single value you need two indexes — one for the row, one for the column: grid[row][column]. The first index selects an inner list; the second selects an element within it.

Because there are two dimensions, you typically process the data with nested loops — an outer loop over the rows and an inner loop over the columns:

two_d.py
grid = [[88, 91, 77],
        [64, 82, 95],
        [70, 73, 68]]

print(grid[1][2])      # 95  (row 1, column 2)

total = 0
for row in grid:
    for value in row:
        total += value
print(total)            # 708
The locked sequence

Tuples

A tuple is an immutable sequence — very much like a list, except that once it's created it cannot be changed. You write one with parentheses instead of square brackets: info = (item1, item2).

Tuples support every operation that only reads a sequence, including:

✓What tuples can do▸
  • Subscript indexing to retrieve elements, including negative indexes
  • Slicing expressions
  • The in, +, and * operators
  • Built-in functions such as len, min, and max
  • The index method
✗What tuples cannot do▸

Because they're immutable, tuples do not provide any method that would change their contents: no append, remove, insert, reverse, or sort. Trying to assign to an element raises a TypeError.

tuples.py
point = (3, 7)

print(point[0])        # 3
print(len(point))      # 2
print(7 in point)      # True

point[0] = 9          # TypeError: tuples can't be changed

Why use a tuple?

  • Speed: processing a tuple is a little faster than processing an equivalent list.
  • Safety: immutability guarantees the data won't be altered by accident.
  • Requirement: some Python operations expect tuples specifically.

When you need to switch between the two, the list() function converts a tuple to a list, and the tuple() function converts a list to a tuple:

convert.py
fixed = (10, 20, 30)
editable = list(fixed)     # [10, 20, 30]  (now mutable)

numbers = [1, 2, 3]
locked = tuple(numbers)    # (1, 2, 3)  (now immutable)
Visualizing data

Plotting list data with matplotlib

Once your data lives in lists, you can turn it into charts. The matplotlib package is a library for creating two-dimensional graphs. It isn't part of the standard library, so it has to be installed separately — once — using Python's pip tool.

install (one time, at a command prompt)
# Windows
pip install matplotlib

# macOS / Linux
sudo pip3 install matplotlib

The drawing functions live in a module named pyplot. The conventional import gives it the short alias plt:

import_plt.py
import matplotlib.pyplot as plt
Not in the browser console

The practice console further down runs Python in your browser and has no window to pop a chart into, so plt.show() won't display there. Run these matplotlib examples in your own installed Python instead. The charts below are illustrations of what each example produces.

A line graph with plot

The plot function draws a line graph that connects a series of points with straight lines. It takes two lists — the X coordinates and the matching Y coordinates — and each pair becomes one point. The title, xlabel, and ylabel functions add captions; xticks and yticks replace the numbers on each axis with your own labels; and grid(True) adds gridlines.

rainfall_line.py
import matplotlib.pyplot as plt

def main():
    month_nums = [0, 1, 2, 3, 4]
    rainfall   = [12, 30, 22, 45, 18]

    plt.plot(month_nums, rainfall, marker='o')
    plt.title('Monthly Rainfall')
    plt.xlabel('Month')
    plt.ylabel('Millimeters')
    plt.xticks([0, 1, 2, 3, 4],
               ['Jan', 'Feb', 'Mar', 'Apr', 'May'])
    plt.grid(True)
    plt.show()

main()

A bar chart with bar

The bar function draws a bar chart. It needs a list of X positions for each bar's left edge and a list of bar heights. A third argument sets the bar width, and the color parameter accepts a tuple of single-letter color codes ('r' red, 'g' green, 'b' blue, 'c' cyan, 'm' magenta, 'y' yellow, 'k' black, 'w' white).

feeders_bar.py
import matplotlib.pyplot as plt

positions = [0, 10, 20, 30, 40]
birds     = [14, 9, 22, 6, 17]

plt.bar(positions, birds, 6, color=('g',))
plt.title('Birds Counted per Feeder')
plt.show()

A pie chart with pie

The pie function turns a single list of values into a pie chart. Python sums the values to get "the whole," and each value becomes a slice sized as its share of that whole. The labels parameter takes a list of strings to name the slices, and colors accepts a tuple of color codes.

budget_pie.py
import matplotlib.pyplot as plt

amounts     = [45, 20, 10, 25]
slice_names = ['Rent', 'Food', 'Transit', 'Savings']

plt.pie(amounts, labels=slice_names)
plt.title('Where the Budget Goes')
plt.show()

Check yourself

Predict each answer, then open the card. Even better, try it in the console above.

Q1What is the one essential difference between a list and a tuple?▸

A list is mutable — its contents can be changed after creation. A tuple is immutable — once created, it cannot be changed.

Q2Given data = [10, 20, 30, 40], what are data[1] and data[-1]?▸

data[1] is 20 (indexing starts at 0). data[-1] is 40, the last element, since negative indexes count back from the end.

Q3What does data[1:3] return, and why isn't index 3 included?▸

It returns [20, 30]. A slice runs from start up to but not including end, so position 3 is left out.

Q4Why is copy = original not a real copy, and how do you make one?▸

That assignment makes both names reference the same list, so editing one shows up in the other. For an independent copy, copy the elements — e.g. original[:], list(original), or a loop that appends each element to a new list.

Q5What's the difference between list.index(x) and list.remove(x) when x isn't present?▸

Both raise a ValueError. When the item is present, index returns the position of its first occurrence, while remove deletes that first occurrence.

Q6Rewrite this as a list comprehension: an empty list, a for loop over prices, and append of each price that is under 20.▸

cheap = [p for p in prices if p < 20]. The expression is just the variable, so nothing is transformed — the if clause is doing pure filtering.

Q7To reach the value in row 2, column 0 of a 2-D list named grid, what do you write?▸

grid[2][0] — the first index selects the row (an inner list), the second selects the column within that row.

Q8Which list methods do tuples not support, and why?▸

append, remove, insert, reverse, and sort — every method that would change the contents. Tuples are immutable, so only read-only operations like indexing, slicing, in, len, min, max, and index are allowed.
