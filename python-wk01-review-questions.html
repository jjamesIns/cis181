  1. Why is a computer described as a general-purpose machine? What single thing determines the job it performs at any given moment?

  2. Name the four major categories of computer hardware, and state in one sentence each what they do.

  3. A student loses two hours of unsaved work during a power outage. Identify the hardware component responsible and the property of that component that explains the loss. What should the student have done differently?

  7. What are the words that make up a high-level programming language called? What are the short words used in assembly language called?

  8. List, in order, the three steps of the cycle a CPU repeats while a program runs, and describe what happens in each step.

Programming Exercises

>>> Open the Interactive Python Console
How to submit. Copy the full text of your console session (or take a screenshot of it) and paste it into the Canvas submission box, followed by your written answers to the items marked Explain. Your transcript must show every line you typed and every line Python printed back.
Exercise 1

Meet the Interpreter

Goal: get comfortable with interactive mode, and see for yourself what happens when you break a syntax rule.

  1. Type 15 + 27 and press Enter. Notice that the interpreter answered without your having to ask it to print anything.
  2. Type 2 ** 8 and press Enter. Explain: in one sentence, what does the number you got back have to do with the eight bits in a byte?
  3. Use the print function to display a sentence that includes your own name — for example, print("My name is Ada").
  4. Type minutes = 90 and press Enter. Nothing appears — that is expected. Now type minutes / 60 and press Enter. Explain: why did the first line print nothing while the second line printed a value?
  5. Now break a rule on purpose. Type print("Hello) — with the closing quotation mark missing — and press Enter. Copy the error message exactly. Explain: what kind of error is this, which rule did you break, and did the statement run at all?
Submit: your console transcript for steps 1–5, plus your written answers for steps 2, 4, and 5.
Exercise 2

Seeing the Bits

Goal: confirm the binary and character-encoding ideas from the module by asking Python to show them to you directly.

  1. Type bin(77). Compare what comes back to Figure 1.2 in the Week 1 concepts page. (The 0b at the front is just Python's way of saying "this is binary.")
  2. Now go the other direction: type int("01001101", 2). The 2 tells Python to read the string as base 2. Explain: what did steps 1 and 2 just demonstrate about the relationship between decimal and binary?
  3. Type 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1, then on the next line type 2 ** 8 - 1. Explain: why do these two very different expressions produce the same number, and what does that number represent?
  4. Type ord("A"), then chr(66). Explain: in one or two sentences, what do these two functions demonstrate about the way characters are stored in memory?
  5. Type ord("9"), then int("9"). Explain: the results are different numbers. What is the difference between the character 9 and the number 9?
  6. Type chr(960). Explain: which encoding standard makes this character possible, and why could the original 128-character ASCII scheme not represent it?
Submit: your console transcript for steps 1–6, plus your written answers for steps 2, 3, 4, 5, and 6.
Tip. If the console gets cluttered, use the Clear button to reset it — but copy your transcript first. Press the ↑ arrow key to bring back a line you already typed instead of retyping it.

Short Answer · 2 points each

  1. Why is a computer a general-purpose machine? Because it has no built-in job of its own. The program (software) currently loaded determines what it does, so the same hardware can edit a photo, route a delivery truck, or forecast the weather depending only on which program is running.
  2. Four major hardware categories. CPU — runs the program's instructions. Main memory (RAM) — holds the running program and its data. Secondary storage — keeps data long-term, even with the power off. Input/output devices — collect data for the computer (keyboard, mouse, camera) and present the computer's results (display, printer).
  3. Lost work in a power outage. Main memory (RAM) is responsible, and the property is volatility — RAM holds data only while it is powered, so its contents vanish the instant power is lost. The student should have saved the work to secondary storage, which retains data without power.
  4. Bit on / bit off. A bit that is turned on represents the number 1; a bit that is turned off represents the number 0.
  5. Bit, byte, and the value 255. A bit (binary digit) is the smallest unit of storage and holds either 0 or 1. A byte is a group of eight bits, enough to store one character or a small number. When all eight bits are 1, the place values 128+64+32+16+8+4+2+1 total 255, so 255 is the largest value; 0 (all bits off) is the smallest.
  6. Storing characters; ASCII vs. Unicode. Each character is assigned a numeric code, and that code is what gets stored in binary — so a name is really a sequence of numbers. ASCII defines codes for only 128 characters, which covers English but not the world's other writing systems. Unicode is backward-compatible with ASCII but extends far beyond it, representing characters from virtually every written language.
  7. High-level words; assembly words. The words of a high-level language are called key words (or reserved words). The short words used in assembly language are called mnemonics.
  8. The three steps of the CPU's cycle. Fetch — read the next instruction from main memory. Decode — determine which operation that numeric code represents. Execute — carry the operation out. The CPU then repeats the cycle, billions of times per second, until the program ends.
  9. Compiler vs. interpreter. Any two of: a compiler translates the entire program at once, while an interpreter translates and runs it one statement at a time; a compiler produces a separate machine language file you can run later without the source, while an interpreter produces no such file; compiled languages include C and C++. Python uses an interpreter.
  10. Interactive mode vs. script mode. In interactive mode you type one statement at a time at the >>> prompt and it runs immediately, but nothing is saved when the session ends — best for experimenting, testing an idea, or checking how something behaves. In script mode you save statements in a .py file and run the whole file — best for any program you want to keep, reuse, or turn in.

Exercises · 3 points each

  1. Bytes to decimal. a. 8+4+2+1 = 15 · b. 64+16+4+1 = 85 · c. 128+1 = 129 · d. 128+64+32+16+8+4+2+1 = 255. Award 1 point for correct sums, 1 for showing place values.
  2. Decimal to eight-bit bytes. a. 5 = 00000101 · b. 40 = 00101000 · c. 100 = 01100100 · d. 200 = 11001000. Leading zeros are required — the question asks for a full byte. Students can check with format(5, '08b').
  3. Two bytes. Two bytes are 16 bits, so there are 216 = 65,536 patterns, and the largest value is 65,535 (one less, because the count begins at 0). Each added bit doubles the number of patterns.
  4. ASCII codes. B = 66, C = 67, Z = 90 (65 + 25), a = 97. Verifiable with ord("Z").
  5. Classify the hardware. a. input device · b. secondary storage · c. main memory · d. output device · e. CPU
  6. System vs. application software. a. system (an operating system) · b. application · c. system (a utility program) · d. application

  1. Step 2 — what does 256 have to do with a byte?Each of the 8 bits has two possible states, so a byte has 28 = 256 distinct on/off patterns. Those 256 patterns represent the values 0 through 255 — which is why 255, not 256, is the largest value a byte can hold.
  2. Step 4 — why did one line print and the other not?minutes = 90 is an assignment: it stores a value in memory and produces no result to display. minutes / 60 is an expression: interactive mode evaluates it and immediately shows the resulting value, 1.5.
  3. Step 5 — what kind of error, and did it run?A syntax error — the rule broken is that a string literal must be closed with a matching quotation mark. The statement never ran: the interpreter could not translate it, so it reported the problem instead of executing anything.

Programming Exercise 2 · Seeing the Bits — 16 points

interactive mode
>>> bin(77)
'0b1001101'
>>> int("01001101", 2)
77
>>> 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1
255
>>> 2 ** 8 - 1
255
>>> ord("A")
65
>>> chr(66)
'B'
>>> ord("9")
57
>>> int("9")
9
>>> chr(960)
'π'
  1. Step 2 — decimal and binary.They are two notations for the same value, not two different numbers. 77 and 1001101 are the same quantity written in base 10 and base 2, and Python can convert freely in either direction. The leading 0 in "01001101" is ignored — it simply pads the value out to a full byte.
  2. Step 3 — why both give 255.The first expression adds the place values of all eight bits when every bit is 1. The second counts the 256 possible patterns in a byte and subtracts one because the counting starts at 0. Both describe the same limit: 255 is the largest value one byte can hold.
  3. Step 4 — what ord and chr show.Characters are not stored as characters; each one is stored as a numeric code. ord reveals the code for a character (A is 65) and chr turns a code back into the character it represents (66 is B) — exactly the process in Figure 1.3.
  4. Step 5 — the character 9 versus the number 9.The character "9" is a symbol stored under code 57, like any other text character; the number 9 is a numeric value the computer can do arithmetic with. Same appearance on screen, entirely different things in memory — which is why input read from a keyboard must be converted before you can calculate with it. This previews the int() conversion in Week 2.
  5. Step 6 — why π is possible.Unicode. The original ASCII scheme defines codes for only 128 characters, so code 960 falls far outside its range. Unicode keeps the ASCII codes intact but extends the numbering far enough to cover Greek and virtually every other writing system.
PointsEarned for
6Complete transcript showing all six steps with correct output.
4Steps 2 and 3: decimal and binary are the same value; 255 is the byte's ceiling.
3Step 4: characters are stored as numeric codes.
3Steps 5 and 6: character "9" ≠ number 9; Unicode extends beyond ASCII's 128 codes.
