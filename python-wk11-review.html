Week 01

Computers and programming

The vocabulary everything else rests on: what the machine is made of, how it stores information, and what a program actually is.

Hardware and software

A computer is a general-purpose machine — the program currently loaded decides what job it does. The four hardware categories are the CPU (runs the instructions), main memory / RAM (holds the running program and its data, and is volatile — erased when power is lost), secondary storage (keeps data without power), and input/output devices. Software divides into system software (the operating system and utilities) and application software (word processors, browsers, games).

Storing numbers and characters

A bit holds 0 or 1; eight bits make a byte. All eight bits on gives 128+64+32+16+8+4+2+1 = 255, the largest value one byte can hold — and 28 = 256 possible patterns counting from 0. Characters are stored as numeric codes: ASCII defines 128 of them, and Unicode extends that to nearly every writing system while keeping the ASCII codes intact.

The distinction to hold onto

The character "9" and the number 9 are different things. ord("9") is 57 — its character code — while the number 9 is a value you can do arithmetic with. This is exactly why keyboard and file input must be converted before you can calculate with it.

How a program works, and using Python

The CPU repeats a three-step cycle: fetch the next instruction, decode it, execute it. It understands only machine language from its own instruction set, so high-level code must be translated. A compiler translates the whole program into a separate executable file; an interpreter translates and runs one statement at a time and produces no such file. Python uses an interpreter. Interactive mode runs statements immediately at the >>> prompt but saves nothing; script mode runs a saved .py file.

A syntax error breaks the language's rules, so the program never runs at all.

Week 02

Input, processing, and output

Designing before coding, then the core statements every program is built from.

Pseudocode and flowcharts

An algorithm is a set of well-defined logical steps. Pseudocode is informal "fake code" with no syntax rules, so you can focus purely on the design. A flowchart draws it: ovals are terminals, parallelograms are input/output, rectangles are processing, and diamonds are decisions. Design is the most important stage — code comes after it.

Input, processing, output

Nearly every program receives input, performs processing on it, and produces output — in that order.

print, strings, comments, and variables

basics.py
# A comment — ignored by the interpreter, written for people
print("Welcome to the trail log.")     # a string literal in quotes
print("Distance:", miles, "miles")      # commas → a space between items

trail_name = "Sunrise Loop"              # = is the assignment operator
elevation = 1240                        # int; 12.5 would be a float

A string is a sequence of characters; a string literal is one written directly in code, in quotes. A variable is a name referencing a value in memory, created by an assignment statement. The three first data types are int, float, and str.

Reading input and performing calculations

calc.py
age = int(input("Enter your age: "))    # nested function call
price = float(input("Enter the price: "))

input always returns a string, so convert with int() or float() before doing math. Operators: + - * /, plus // (integer division, truncates), % (remainder), and ** (exponent). * and / outrank + and -; parentheses override. An int combined with a float produces a float.

Concatenation, escape sequences, and suppressing the newline

output.py
greeting = "Welcome, " + "traveler!"     # + joins two strings

print("Name:\tAda\nLevel:\t7")            # \t tab, \n newline
print("Loading", end="...")              # end= replaces the newline
print("2025", "11", "30", sep="-")       # sep= replaces the space

Formatting output, and named constants

formatting.py
print(format(12345.678, ",.2f"))          # 12,345.68
print(f"Total: {total:,.2f}")              # same, as an f-string
print(f"Rate: {rate:.2%}")                 # 8.25%

SALES_TAX = 0.0725                          # named constant, ALL_CAPS
total = subtotal * SALES_TAX

An f-string is a literal prefixed with f whose braced placeholders are replaced by the values inside them; a format specifier follows a colon. A named constant replaces a magic number — it makes code self-documenting, changeable in one place, and safe from retyping errors.

Week 03

Decision structures

Teaching a program to choose a path.

decisions.py
# single alternative — one optional path
if temperature > 28:
    print("Fan ON")

# dual alternative — exactly one of two paths always runs
if member_id != 0:
    print("Welcome back")
else:
    print("See the front desk")

# multiple alternative — first true condition wins, rest are skipped
if aqi <= 50:
    print("Good")
elif aqi <= 100:
    print("Moderate")
else:
    print("Unhealthy")

Every if clause ends in a colon, and indentation — not braces — marks the block. A Boolean expression is one that is True or False; build one with a relational operator: > < >= <= == !=. A single = assigns; a double == compares.

Comparing strings

String comparison is case-sensitive — "Start" == "start" is False. Ordering compares character by character using each character's numeric code, stopping at the first difference. Because uppercase codes are lower than lowercase, "Banana" < "apple" is True. If one string is a prefix of another, the longer one is greater.

Logical operators and Boolean variables

OperatorResult is True when…
andboth sides are true
orat least one side is true
notthe single operand is false (it flips the value)

Short-circuit evaluation stops as soon as the answer is certain, which lets the left side guard the right: count != 0 and total / count > 10 never divides by zero. For ranges, inside uses and (temp >= 18 and temp <= 24) and outside uses or (temp < 18 or temp > 24).

A Boolean variable holds True or False and is often used as a flag: initialize it to False, set it to True when the condition occurs, and test it bare — if found:, never if found == True:.

Week 04

Repetition structures

Two kinds of loop, and the four patterns you will use them for.

loops.py
# condition-controlled — repeats while a condition holds
seconds = 5
while seconds > 0:
    print(seconds)
    seconds -= 1          # without this: an INFINITE loop

# count-controlled — repeats a known number of times
for n in range(1, 6):     # 1, 2, 3, 4, 5 — the limit is EXCLUDED
    print(n, n ** 2)

while is a pretest loop: if the condition is false at the start, the body never runs. range takes a limit, a start and limit, or a start, limit, and step — and a negative step counts down.

Accumulating a total, and augmented assignment

An accumulator starts at 0 before the loop and grows inside it. Initializing it inside would reset it every pass.

accumulate.py
total = 0.0
for amount in expenses:
    total += amount        # += -= *= /= %= are augmented assignment
average = total / len(expenses)

Sentinels, input validation, and nested loops

patterns.py
# SENTINEL — a value that cannot appear in the real data
score = int(input("Score (-1 to finish): "))   # priming read
while score != -1:
    total += score
    score = int(input("Score (-1 to finish): "))  # read again!

# INPUT VALIDATION — loop while the input is BAD
rating = int(input("Rate 1-5: "))
while rating < 1 or rating > 5:
    print("Not between 1 and 5.")
    rating = int(input("Rate 1-5: "))

# NESTED — inner runs fully for EACH pass of the outer
for row in range(1, 4):
    for seat in range(1, 5):
        print(row, seat)      # 3 × 4 = 12 lines total

A sentinel loop needs two input statements — the priming read before, and a matching read at the bottom. Total nested iterations are inner count × outer count.

Week 05

Functions

Splitting a program into named pieces — the divide-and-conquer approach.

functions.py
def show_area(width, height):      # VOID — does something, returns nothing
    print("Area:", width * height)

def to_celsius(fahrenheit):        # VALUE-RETURNING — hands a value back
    return (fahrenheit - 32) * 5 / 9

show_area(8, 3)                     # 8 and 3 are ARGUMENTS
c = to_celsius(212)                 # width/height are PARAMETERS
book_room(guests=2, nights=3)        # keyword arguments — order free

A function definition is the def header plus its indented block; defining does not run it — a call does. Arguments match parameters by position unless named. Python passes by value: the function gets a copy, so reassigning a parameter never changes the caller's variable.

Scope, globals, and modules

A local variable is created inside a function and exists only there; its scope runs from its assignment to the end of that function. A global variable is assigned outside all functions — readable anywhere, but a function needs the global keyword to reassign it. Globals are discouraged; a global constant in ALL_CAPS is fine, and needs no global keyword because it is only read.

modules.py
import random, math
random.randint(1, 6)        # both ends included
random.randrange(0, 35, 5)   # limit excluded, like range
math.sqrt(144)              # 12.0 — always a float

Module functions are reached with dot notation. Random numbers are pseudo-random: a seed initializes the formula, so random.seed(7) makes the same series repeat.

Week 06

Exceptions

Runtime errors, how to catch them, and how your own functions should report trouble.

An exception is an error that occurs while the program runs — unlike a syntax error, earlier statements already executed. Unhandled, it halts the program and prints a traceback; read it bottom-up, where the last line names the type and describes the problem.

handling.py
try:
    age = int(input("Age: "))
except ValueError as err:
    print("Not a number:", err)   # err is the exception object
else:
    print("Accepted")              # only if nothing was raised
finally:
    print("Done")                  # every time — used for cleanup

When an exception is raised, the rest of the try suite is skipped. List an except clause per type; a bare catch-all must come last. Common types: ValueError, TypeError, ZeroDivisionError, IndexError, KeyError, NameError, FileNotFoundError.

Raising from your own functions

raising.py
def to_kelvin(celsius):
    if celsius < -273.15:
        raise ValueError("below absolute zero")
    return celsius + 273.15

class TemperatureError(Exception):   # custom type
    pass

The principle: a function detects the problem, the caller decides the response. raise ends the function immediately. Raise for the exceptional, return a value for the normal. An unhandled exception propagates up the call chain until something catches it.

Week 07

Files

Making data outlive the program that created it.

Three steps every time: open, process, close. Modes: 'r' read (error if absent), 'w' write (erases existing contents), 'a' append (keeps them). Both 'w' and 'a' create the file if it doesn't exist.

files.py
outfile = open("scores.txt", "w")
outfile.write(str(score) + "\n")   # str() AND \n — both required
outfile.close()

infile = open("scores.txt", "r")
for line in infile:                  # no priming read, stops automatically
    total += int(line)              # everything read is a STRING
infile.close()

write adds no line breaks and accepts only strings. read() returns the whole file; readline() returns one line including its '\n', which rstrip('\n') removes. At end of file readline returns an empty string, which serves as the sentinel in a while version. A record is one item's complete data; a field is one piece of it.

Closing safely

Put close() in a finally suite. If an exception fires partway through the try, a close() at the bottom of that suite is skipped and the file is left open.

Week 08

Lists and tuples

Ordered collections — one you can change, one you cannot.

lists.py
data = [10, 20, 30, 40, 50]
data[0]        # 10 — first index is 0
data[-1]       # 50 — last element
data[1:4]      # [20, 30, 40] — end is EXCLUDED, returns a NEW list
len(data)      # 5 — so the last valid index is len - 1

data.append(60)      # add to the end
data.insert(0, 5)     # by POSITION
data.remove(30)      # by VALUE — first occurrence only
del data[2]         # by POSITION
data.sort()          # in place — RETURNS None

append, insert, remove, sort, and reverse all change the list in place and return None. index and remove raise ValueError when the value is absent; a bad index raises IndexError.

Copying, comprehensions, 2-D lists, tuples

more_lists.py
alias = original       # NOT a copy — both names, one list
copy = original[:]     # a real copy (also list(original))

feet = [round(m * 3.28) for m in meters]   # transforms
big  = [d for d in donations if d > 30]     # filters

grid = [[88, 91], [64, 82]]
grid[1][0]            # 64 — row index, then column index

point = (3, 7)         # tuple — immutable
point[0] = 9           # TypeError

A list comprehension is [expression for variable in iterable], optionally followed by an if clause. The expression transforms; the if clause filters. Tuples support every read operation — indexing, slicing, in, len — but none that would change them. Convert with list() and tuple().

Week 09

Strings

A string is a sequence too — with one crucial difference from a list.

Indexing, slicing, in, len, iteration, and * all work on strings. But strings are immutable: tag[0] = "H" raises TypeError. Every method that appears to modify a string actually returns a new copy.

strings.py
code = "ORD-48715"
code[0:3]                 # 'ORD'
code[4:]                   # '48715'

# TESTING — return True/False
"2026".isdigit()          # True  ("12.5" → False!)
"Falcon".isalpha()        # True
"Bay12".isalnum()         # True  ("Bay 12" → False)

# MODIFYING — return a COPY; you must capture it
label = label.strip()      # also lower(), upper(), lstrip(), rstrip()

# SEARCHING
sentence.find("brown")     # 10, or -1 if absent — NOT an exception
sentence.replace("fox", "cat")
sku.startswith("BOLT")     # also endswith()
sentence.split()            # → a LIST of words; split(",") for commas

Comparisons are case-sensitive, so compare with answer.lower() == "yes". Use in for a yes/no answer and find when you need the position.

Week 10

Dictionaries and sets

Lookup by key, and collections of unique items.

dicts.py
slots = {"A1": "pretzels", "A2": "almonds"}   # key: value
slots["A1"]                  # by KEY, never by position
slots["B2"] = "cashews"      # adds if new, REPLACES if the key exists
del slots["A2"]              # KeyError if absent — guard with in

slots.get("C9", 0)          # safe lookup — a default, never KeyError
for key, value in slots.items():   # both at once
    print(key, value)

Keys must be immutable and are unique; values can be anything. in tests keys, not values. A plain for loop gives keys; items() gives pairs. Methods: get, keys, values, items, pop, popitem, clear.

sets.py
unique = set([204, 118, 204])   # duplicates collapse → 2 items
empty = set()                    # {} is an empty DICTIONARY

roster.add("Ravi")              # one item
roster.update(["Kim", "Lee"])    # several
roster.discard("Jordan")        # safe; remove() raises KeyError

py | ja      # union — in either
py & ja      # intersection — in both
py - ja      # difference — ORDER MATTERS
py ^ ja      # symmetric difference — in one but not both
required.issubset(completed)

Sets are unique, unordered (no indexing), and may mix types. Serializing — called pickling in Python — writes an object to a file as bytes; use modes "wb" and "rb".

Exam prep

The ten traps that cost the most points

Every one of these produces code that looks right. Learn to spot them on sight.

Looks fine, but…What actually happens
counts = counts.sort()sort returns None, so the list is destroyed. Call it as its own statement.
label.strip() on its own lineStrings are immutable — the copy is discarded. Write label = label.strip().
total = total + input(...)input returns a string. Convert with int() or float() first.
while count > 0: with no updateInfinite loop. Something in the body must move toward the stopping point.
Sentinel loop with one inputThe same value is tested forever. You need a priming read and a read inside.
range(1, 10) to reach 10The limit is excluded — it stops at 9. Use range(1, 11).
temp < 18 and temp > 24Can never be true. "Outside a range" always needs or.
alias = original to copy a listBoth names reference one list. Use original[:] or list(original).
"pretzels" in slotsin searches dictionary keys, not values — this is False.
empty = {} for a setThat is an empty dictionary. An empty set is set().
