True or False

10 × 1 pt = 10
  1. T / F

    Because pseudocode has no syntax rules, you do not have to worry about syntax errors while writing it.

  2. T / F

    The Python interpreter ignores everything that appears on a line after the # character.

  3. T / F

    Variable names in Python may contain spaces, as long as the name does not begin with one.

  4. T / F

    Python treats total, Total, and TOTAL as the same variable.

  5. T / F

    You may use a variable in an expression before any value has been assigned to it.

  6. T / F

    In a math expression, multiplication and division are performed before addition and subtraction.

  7. T / F

    The expressions 7 / 2 and 7 // 2 produce the same value.

  8. T / F

    The format function changes the value stored in the variable it is given.

  9. T / F

    A placeholder inside an f-string may contain only a variable name, never a calculation.

  10. T / F

    Using the placeholder {val + 2} in an f-string permanently increases the value stored in val by 2.

Exercise 1

Concert Ticket Total

A venue charges a flat service fee on every ticket sold, and sales tax is applied to the tickets and fees together. Write a program that reads the ticket price and the number of tickets, then displays the subtotal, the fees, the tax, and the grand total.

  1. Start with two named constants: SERVICE_FEE = 4.75 and TAX_RATE = 0.0825.
  2. Read the input: ticket_price = float(input("Ticket price: ")) and quantity = int(input("Number of tickets: ")). Use 68.50 and 3 as your test values.
  3. Do the processing, one statement per line: subtotal is the price times the quantity; fees is the service fee times the quantity; tax is the tax rate applied to the subtotal plus the fees; total is all three added together.
  4. Display total on its own line, with no formatting. Explain: copy exactly what Python printed. Why is that not an acceptable thing to show a customer?
  5. Now display all four amounts using format with the specifier ",.2f" so each shows two decimal places.
  6. Now produce the same four lines a second way, using f-strings — for example print(f"Subtotal: {subtotal:,.2f}"). Explain: which of the two versions was easier to read, and why?
  7. Explain: label each statement you wrote as input, processing, or output. Then explain why quantity uses int while ticket_price uses float, and give one reason the two constants are better than typing 4.75 and 0.0825 directly into the formulas.
Submit: your console transcript for steps 1–6, plus your written answers for steps 4, 6, and 7.
Exercise 2

Study-Time Converter

A study-tracking app records total minutes. Write a program that converts a total number of minutes into whole hours plus leftover minutes, and reports the same figure two other ways.

  1. Read the input: total_minutes = int(input("Total minutes studied: ")). Use 227 as your test value.
  2. Before you press Enter on the next two lines, write down your prediction for each. Then run hours = total_minutes // 60 and minutes = total_minutes % 60, and display both variables.
  3. Display the result as a sentence, for example: You studied 3 hours and 47 minutes.
  4. Display the same figure in clock form using the sep argument so the output is exactly 3:47.
  5. Now run total_minutes / 60 — note the single slash. Explain: how does this result differ from what // gave you in step 2, and why would // and % be the right tools for this particular job?
  6. Display that decimal result rounded to two places using format.
  7. Finally, write one print statement that uses the escape sequences \t and \n to produce this tab-aligned, two-line output:
    target output
    Hours:      3
Minutes:    47
Submit: your console transcript for steps 1–7, your written predictions from step 2, and your written answer for step 5.

Short Answer · 2 points each

  1. What does a programmer do first to understand a problem?Talks with whoever wants the program built and asks questions about the details, capturing the answers as the software requirements — the things the finished program must do.
  2. What is pseudocode, and why write it first?An informal "fake code" language with no syntax rules that is never compiled or run. Because you can ignore syntax, you focus entirely on the logic of the design; once the design is right, it can be translated into any real language.
  3. The three typical steps.Input (receiving data while the program runs), processing (performing work on that data, often a calculation), and output (sending the result back) — in that order.
  4. String vs. string literal.A string is any sequence of characters used as data. A string literal is a string written directly into the code, which is why it must be enclosed in quote marks. Accept: the literal is how you write a string into the source; the string is the data itself.
  5. Why write comments?They are written for the humans who read the code — including the author months later. They explain purpose and intent, which the code itself does not convey.
  6. Four variable naming rules.Any four of: it cannot be a Python key word; it cannot contain spaces; the first character must be a letter or an underscore, never a digit; after the first character only letters, digits, and underscores are allowed; names are case sensitive. Choosing a descriptive name is a convention, not a rule — accept it only as a fifth item.
  7. int + float → ?A float. In a mixed-type expression the int is temporarily converted to a float, so the result keeps the fractional precision rather than discarding it.
  8. Floating-point vs. integer division./ performs floating-point division and always produces a float, keeping the fractional part (7 / 2 → 3.5). // performs integer division, dropping the fraction (7 // 2 → 3); positive results truncate toward zero and negative results round away from zero.
  9. Magic numbers.An unexplained numeric value sitting in code. Three problems: its purpose is hard to determine; if the same value appears in several places, changing it means finding every copy; and retyping it invites a typo that is very hard to track down.
  10. What is an f-string, and what is its advantage?A string literal prefixed with f, in which braced placeholders are replaced by the values of the expressions inside them when the statement runs. The advantage is that you write the sentence exactly as it should appear and drop values into position, rather than assembling it from comma-separated pieces and relying on print to insert spaces — so spacing and punctuation are fully under your control. Accept also: format specifiers can be attached directly to each placeholder.
  11. Two advantages of TAX_RATE.Any two of: the code becomes self-documenting, since the name explains what 0.0825 means; maintenance is easier, because changing the one assignment updates every use; and it is less error-prone, since the actual number is typed only once.

Algorithm Workbench · 1 point each (16 items)

  1. Prompt for a city.city = input("Enter the name of a city: ") — any reasonable prompt text is fine.
  2. Prompt for weight as a float.weight = float(input("Enter your weight: ")) — the float conversion must wrap the input call.
  3. Four assignment statements.y = x + 12 · z = y * 5 · x = z / 2.5 · y = x - 7. Watch for reversed sides — the receiving variable must be on the left.
  4. Values of result (a = 9, b = 4, c = 12, d = 3).a. 21 · b. 3 · c. 1 · d. 81 · e. 4.0 — note that c / d gives a float even though the division comes out even.
  5. Sum of 18 and 32.total = 18 + 32
  6. Sale price.sale_price = list_price - discount
  7. Trace 1.10 — * outranks +, so y * z (3 × 2 = 6) happens first, then 4 + 6.
  8. Trace 2.30 — the second assignment replaces the first; count now references 30 and the value 12 is discarded.
  9. Two decimal places.print(format(total, '.2f')) → displays 1234.57
  10. Comma separator, one decimal.print(format(population, ',.1f')) → displays 8,472,913.3
  11. sep='|'red|green|blue — no spaces, because sep replaces the default single space.
  12. F-string sentence.print(f"It is {temp} degrees in {city}.") — both placeholders required; a version built from comma-separated arguments does not answer the question as asked.
  13. Comma separator, two decimals.print(f"{balance:,.2f}") → displays 48,213.46
  14. Left-aligned field.[Ada     ] — the name occupies 3 of the 8 positions and is left-aligned by the < designator, leaving five trailing spaces before the closing bracket.
  15. Operators inside an f-string.3 and 1 — each placeholder is evaluated independently: 7 // 2 truncates to 3, and 7 % 2 gives the remainder 1.
  16. Replace the magic number.TAX_RATE = 0.0825 then total = subtotal * TAX_RATE. Any descriptive all-caps name is acceptable.

Exercise 1 · Concert Ticket Total — 14 points

interactive mode
>>> SERVICE_FEE = 4.75
>>> TAX_RATE = 0.0825
>>> ticket_price = float(input("Ticket price: "))
Ticket price: 68.50
>>> quantity = int(input("Number of tickets: "))
Number of tickets: 3
>>> subtotal = ticket_price * quantity
>>> fees = SERVICE_FEE * quantity
>>> tax = (subtotal + fees) * TAX_RATE
>>> total = subtotal + fees + tax
>>> print(total)
237.879375
>>> print("Subtotal:", format(subtotal, ",.2f"))
Subtotal: 205.50
>>> print("Fees:", format(fees, ",.2f"))
Fees: 14.25
>>> print("Tax:", format(tax, ",.2f"))
Tax: 18.13
>>> print("Total:", format(total, ",.2f"))
Total: 237.88
# Step 6 — the same four lines written as f-strings
>>> print(f"Subtotal: {subtotal:,.2f}")
Subtotal: 205.50
>>> print(f"Total:    {total:,.2f}")
Total:    237.88
  1. Step 4 — why the raw total is unacceptable.It displays as 237.879375 — six decimal places, which is not a valid amount of money. Currency must be shown to exactly two decimal places, which is what the ",.2f" specifier produces.
  2. Step 6 — input, processing, output.The two input lines are input; the four calculation lines (subtotal, fees, tax, total) are processing; the print lines are output. The two constant assignments are setup — accept them as either processing or "neither," as long as the reasoning is stated.
  3. Step 6 — int vs. float.A quantity of tickets is a whole number and cannot be fractional, so int fits. A price has cents, so it needs float to preserve the fractional part. Accept also: int("68.50") would raise an error.
  4. Step 6 — why constants.Any one of the three standard reasons: self-documenting, single point of maintenance when the fee or rate changes, and the number gets typed only once so typos are less likely.
PointsEarned for
6Working transcript: constants, both conversions, all four calculations correct, formatted output.
3Step 6 — the four lines reproduced with f-strings, plus a reasoned comparison of the two styles.
2Step 4 — identifies the six-decimal result as unusable currency.
3Step 7 — input / processing / output labeling, plus int vs. float and one advantage of named constants.
Common error to watch for. Writing tax = subtotal * TAX_RATE and omitting the fees. The parentheses in (subtotal + fees) * TAX_RATE are what make the tax apply to both — a direct application of the precedence rules from Section 7.

Exercise 2 · Study-Time Converter — 14 points

interactive mode
>>> total_minutes = int(input("Total minutes studied: "))
Total minutes studied: 227
>>> hours = total_minutes // 60
>>> minutes = total_minutes % 60
>>> hours
3
>>> minutes
47
>>> print("You studied", hours, "hours and", minutes, "minutes.")
You studied 3 hours and 47 minutes.
>>> print(hours, minutes, sep=":")
3:47
>>> total_minutes / 60
3.783333333333333
>>> print(format(total_minutes / 60, ".2f"))
3.78
>>> print("Hours:\t" + str(hours) + "\nMinutes:\t" + str(minutes))
Hours:      3
Minutes:    47
Step 7 has more than one right answer. print("Hours:\t", hours, "\nMinutes:\t", minutes) also works but inserts extra spaces from the default separator; print("Hours:\t3\nMinutes:\t47") hard-codes the values. Full credit for any version producing the two tab-aligned lines; note in feedback which approach generalizes.
  1. Step 2 — predictions.hours is 3 and minutes is 47. Award the point for a recorded prediction whether or not it was right — the prediction is the assessed behavior.
  2. Step 5 — / versus //./ gives 3.783333333333333, a float carrying the leftover time as a fraction of an hour. // gives 3, discarding that fraction. For this job you want whole hours and whole leftover minutes, and 0.7833 of an hour is not a usable answer — // supplies the whole hours and % supplies exactly the remainder that // threw away, so together they account for all 227 minutes.
